# Perfect Pitch Trainer

An ear-training game: listen to a pitch, then click the key(s) you heard.

**[Try it live](https://john-pat10.github.io/perfect-pitch-trainer/)**

- 1, 2 or 3 notes at a time
- All keys, white keys only, or black keys only
- Synth or piano sound, in low, mid or high octaves
- Current streak, best streak and daily streak, saved in your browser

Built with JavaScript and [Tone.js](https://tonejs.github.io/). To run it locally, open `index.html` in any browser.
